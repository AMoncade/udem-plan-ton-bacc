# Brief — chantier UI

## Ce que tu possèdes
`app/**`, `components/**`, `app/globals.css`.

## Ce que tu ne touches pas
`lib/**` en entier (contrat gelé + moteur), `scripts/**`, `data/**`.

## Objectif
Trois vues sur le catalogue, contre **la fixture**
(`data/fixtures/actuariat-verifie.fixture.json`), jamais contre
`data/catalogue.json` qui n'existe pas encore. Le jour où le scraper livre,
seule la source de données change.

1. **Arbre des préalables** — cours verrouillés / disponibles / faits /
   avertissement, arêtes depuis les noeuds `et`/`ou`. Les états viennent de
   `DiagnosticCours`, déjà typé dans `lib/types.ts`.
2. **Audit des blocs** — par bloc : crédits attribués, manquants, perdus
   au-delà du maximum, conformité. Plus la conformité globale et la liste
   `Audit.problemes`.
3. **Planificateur par trimestre** — placer un cours dans un trimestre, avec la
   contrainte d'offre réelle : `Cours.trimestres` dit quand le cours existe.
   Placer ACT 2251 à l'automne doit être refusé visiblement. **C'est la
   fonctionnalité qui distingue ce projet** : la moitié du bloc 75C est
   hiver-seulement, donc l'étudiant ne peut pas répartir librement.

L'état de l'étudiant (cours faits, plan) vit dans `localStorage`. Pas de base de
données, pas d'authentification.

## Le moteur n'existe pas encore — et ce n'est pas bloquant
`lib/engine/index.ts` est écrit en parallèle par une autre session. Sa surface
est **déjà gelée** dans `docs/CONTRAT.md` :

```ts
diagnostiquerCours(catalogue, faits): Map<CodeCours, DiagnosticCours>
auditProgramme(programme, catalogue, faits): Audit
```

Code contre ces signatures et contre les types `DiagnosticCours` / `Audit` /
`EtatBloc` de `lib/types.ts`. Si tu as besoin de données avant que le moteur
livre, fabrique un faux **dans ton propre répertoire** (`app/_demo/`), jamais
dans `lib/`. N'invente pas d'autres noms de fonctions : l'UI et le moteur se
rejoignent exactement sur ces deux-là.

## Langue et ton
Interface en **français**. Les données sources sont françaises (blocs, segments,
préalables) ; traduire ne produirait que des erreurs de correspondance.

Thème sombre, identité visuelle propre — pas le gabarit Tailwind par défaut. Cet
outil va se faire regarder par des étudiants : il doit avoir l'air d'un outil,
pas d'une démo. Aucun logo ni marque UdeM : projet personnel sans affiliation.

## Ce que je crois vrai — vérifie
Les 8 blocs de la fixture viennent de la vraie page de structure, mais **seuls 3
cours sur 55 ont une fiche**. Ton UI doit afficher proprement un cours référencé
sans fiche (titre inconnu, crédits inconnus) au lieu de planter ou d'afficher
« undefined ». C'est l'état normal jusqu'à ce que le scraper livre, et ça
restera possible après.

## Terminé quand
`npm run build` passe, `npm test` vert, les trois vues fonctionnent sur la
fixture, et un cours sans fiche s'affiche correctement.
